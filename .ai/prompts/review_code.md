# REVIEW_CODE.md

## Objective

Review the provided code as a Senior Software Engineer.

Evaluate it against ERP Pulse standards.

---

## Review Checklist

* Architecture
* Clean Code
* SOLID Principles
* Service Layer usage
* Repository Pattern
* Performance
* Security
* Error Handling
* Logging
* Readability
* Maintainability

---

## Output Format

### Strengths

List what is implemented well.

### Issues

List all problems found.

### Severity

Classify each issue:

* Critical
* Major
* Minor

### Improvements

Suggest concrete code improvements.

Do not rewrite the entire implementation unless requested.
