# WRITE_TESTS.md

## Objective

Generate comprehensive tests for the provided feature.

---

## Requirements

Write tests for:

* Success cases
* Validation failures
* Authorization
* Edge cases
* Error handling

---

## Backend

Use Django's testing framework or pytest (whichever the project adopts).

Test:

* Services
* Repositories
* API endpoints

Avoid testing framework internals.

---

## Output

* Test files
* Test cases
* Coverage summary
