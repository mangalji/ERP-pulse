after code change in applicaiton:
    in backend:
        1. docker compose build backend
        2. docker compose up -d backend
    
    in frontend:
        1. docker compose build frontend
        2. docker compose up -d frontend


    if docker-compose.yml or nginx.conf changes:
        1. docker compose up -d --build frontend

        if want to forcefully recreate:

        docker compose up -d --force-recreate

        if want to recreate everything from start:
        
            docker compose down
            docker compose up -d

one liner:

    1. docker compose up -d --build frontend == docker compose build frontend + docker compose up -d frontend




cheat sheet for project:
Change	                    what need to do
Backend .py code    	    docker compose up -d --build backend
Frontend .jsx/.js/.css	    docker compose up -d --build frontend
